# Contributing

Thanks for your interest in Amiga-inspired Lila Night!

## How design decisions are made

This is a personal theme with a clear look. **The design direction is decided by the maintainer.**
The palette in the README is the source of truth: dark plum (never pure black), lavender accents,
a turquoise frame on the active window, a soft pink terminal cursor and a very readable terminal.

That doesn't mean ideas are unwelcome – it means: **talk first, then code.**

## Very welcome

- **Bug reports:** something looks wrong, an install step fails, text is hard to read.
  Please add a screenshot, your distro and your desktop version.
- **Ports to other desktops or apps** (GNOME, Xfce, terminals, editors …), as long as they
  stick to the palette. Put them in their own folder like [`kde/`](kde/).
- **Fixes for other distros** (package names, paths, install script).

## Please open an issue first

- Changes to colors, the overall look or the wallpapers.
- Anything that changes the default install behaviour.

Pull requests that change the design without an issue may be closed without discussion.
If you want a different look, feel free to fork – the MIT license allows that, and that's
what forks are for.

## Rules for contributions

- Contributions are accepted under the project's **MIT** license.
- No original AmigaOS artwork, icons or fonts in the repo – only own or freely licensed work.
- Publicly it stays **"Amiga-inspired"**: *Amiga* and *AmigaOS* are trademarks of their owners.
